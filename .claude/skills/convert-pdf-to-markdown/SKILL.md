# 產品 pdf 檔案轉換成 markdown 格式

## 流程

1. **判斷來源**
   - 若使用者給定 pdf 檔案，進行下一步

2. **檢查工具**
   - 檢查 MCP 工具是否存在，如果沒有請停止回報問題

3. **資料處理**
   - 對清單中每個 pdf，呼叫 `getArticle(source)` 取得文字檔
   - 分析文字檔，找出表格的位置
   - 表格內容會出現兩次，分別來自文字擷取以及表格偵測，只保留表格資訊
   - 根據原先文章的結構順序，把內容與表格編排完整
   - 請不要添加或是補充任何非文章內容以外的資訊，只做排版

4. **儲存報告**
   - 將每份報告以 Markdown 格式存到 `.data/markdown/{原始檔案名稱}.md`
